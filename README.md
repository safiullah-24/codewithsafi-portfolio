## Local Development

Requirements:

- Node.js `22.13+`
- pnpm `11.25.0`

Install dependencies:

```bash
pnpm install --frozen-lockfile
```

Run locally:

```bash
pnpm dev
```

## Production Build

```bash
pnpm exec vite build --config vite.vercel.config.ts
```

## Routes

- `/` — Main portfolio
